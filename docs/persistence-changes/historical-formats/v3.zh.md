# Session V3 持久化格式

[English](v3.md) | 中文

## 概述

查阅 `dsh-v0.1.5-alpha.1` 对应的 V3 持久化类型。header 要求受保护的系统头：系统提示词文本从 `request/header.data.header.system` 迁移到独立的 `system/message` 事件，PTC 派发事件使用已发布的名称，header 新增可选的 `agentPreset` 字段。本快照保留 V4 header-origin 变更之前的 V3 声明。

## 来源证据

来源为已发布 tag `dsh-v0.1.5-alpha.1`，其写入器常量为 3。[tag 记录](../releases/dsh-v0.1.5-alpha.1.zh.md)说明相邻发布之间的变化。本完整目录同时包含未变化的根类型和该 tag 变化的根类型。

<a id="characteristics"></a>
## 格式特征

以下事实描述所选检查点。下方生成的表格保留精确的字段类型与可选性。

- `SessionHeader.version` 解析为字面量 3。header 携带可选的 `origin` 与 `agentPreset` 字段；`origin` 的取值封闭于字面量 `"subagent"`。
- 系统提示词文本通过锚定到打开 step 的 `system/message` 事件传输；`request/header.data.header` 不再内嵌 `system` 成员。
- PTC 派发事件命名为 `tool/ptc-dispatch-start` 与 `tool/ptc-dispatch`；surface 替换操作使用已发布的 `startSeq` / `endSeq` 端点。

[V3 codec](../../../packages/session/session-format-v2-to-v3/src/codec.ts)负责每行一个事件的编码、范围编码的来源引用、受保护的系统头关系，以及从 `session/end-seed` 标记推导的继承切点。[V2 到 V3 规范](../../../packages/session/session-format-v2-to-v3/README.zh.md#v2-to-v3-specification)负责系统消息插入、PTC 事件名称与规范信封转换。

对于已继承的 V3 Session，最后一个携带 `data.inherited: true` 的 `session/end-seed` 事件以其序号位置标识继承切点。物理 `sourceEventSeqs` 可以使用范围编码；逻辑 schema 保留展开后的数值数组。

<a id="verification"></a>
## 验证与限制

[仅来源提取器](../../../scripts/persistence-schema.ts)运行于 TypeScript 6.0.3。重建会省略冗余的 `object` 交叉成员并丢弃规范化不可达的类型定义；它保留现有的 `any` / `unknown`，也不会用 opaque 类型替代未解析的导入。V3 根摘要与从已发布 tag 重建的 V3 写入器状态一致。

历史 surface 事件声明允许可选的 `surfaceOp`。这是已声明类型的保留证据，不表示 codec 或迁移验证器允许省略字段。opaque 值、外部插件事件、紧凑正文编码与运行时关系不在类型清单覆盖范围内。

```sh
pnpm run verify-persistence-formats
```

该检查仅使用当前 checkout 验证到当前写入器为止的每个格式、schema 完整性、双语声明与生成表格。它不重放历史应用，也不建立迁移安全性。维护规则见[格式索引](README.md)，当前声明见[当前目录](../../persistence-catalog.md)。
